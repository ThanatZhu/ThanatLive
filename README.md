# ThanatLive

เกมโต้ตอบสำหรับ TikTok LIVE พร้อม 52 เกมและระบบอัปเดตในแอป

**[ดาวน์โหลดชุดติดตั้งล่าสุด](https://github.com/ThanatZhu/ThanatLive/releases/latest)**

## ติดตั้ง

1. ดาวน์โหลด `ThanatLive-1.1.0.zip` จากหน้า Releases แล้วแตก ZIP ทั้งหมดลงโฟลเดอร์ เช่น `Documents/ThanatLive`
2. ปิด TikTok LIVE Studio ให้หมด แล้วเปิด `Open-Studio.bat`
3. เปิด `Start.bat` และเก็บหน้าต่างตัวเชื่อมไว้ระหว่างใช้งาน
4. เข้าสู่ระบบด้วยบัญชีที่ผู้ขายเปิดสิทธิ์ให้ มีเกมฟรีให้ทดลอง 1 เกม
5. ใน LIVE Studio เพิ่ม Link source: `http://127.0.0.1:21213/live.html` ขนาด 576 × 1024

## ลูกค้าเดิม

ถ้ารุ่นเดิมแจ้งว่ายังไม่ได้ตั้งลิงก์อัปเดต ให้จบไลฟ์ ปิด LIVE Studio และตัวเชื่อม สำรองโฟลเดอร์เดิม แล้วแตกชุดใหม่ทับโฟลเดอร์เดิมหนึ่งครั้ง ชุดนี้ไม่มีไฟล์บัญชี คีย์ใช้งาน หรือการตั้งค่าส่วนตัวของลูกค้า จึงเก็บไฟล์เดิมไว้

จากรุ่น 1.1.0 เป็นต้นไป เปิดเมนู **อัปเดต → ตรวจอัปเดต → ติดตั้งและเปิดใหม่** หลังจบไลฟ์ โปรแกรมตรวจลายเซ็นก่อนติดตั้ง

## รุ่น 1.1.0

- ครบ 52 เกม รวมมีมแดนซ์คลับ 12 ท่าและลานพรเก้าองค์ภาพใหม่
- หน้าทดสอบเชื่อมกับเกมที่เลือกอัตโนมัติ
- เมนูอัปเดตแสดงเวอร์ชันและสถานะดาวน์โหลด
- มี Node และไฟล์ภาพ/ฟอนต์ที่เกมใช้ในชุดติดตั้งแล้ว

พื้นที่นี้ใช้เผยแพร่ชุดติดตั้งและข้อมูลอัปเดตของ ThanatLive สิทธิ์ใช้งานเกมเต็มขึ้นอยู่กับบัญชีที่ผู้ขายเปิดให้
