# ThanatLive

เกมโต้ตอบสำหรับ TikTok LIVE พร้อม 52 เกม และตัวช่วยตั้งค่าครั้งแรกทีละขั้น

**[ดาวน์โหลด ThanatLive 1.2.2 สำหรับ Windows](https://github.com/ThanatZhu/ThanatLive/releases/download/v1.2.2/ThanatLive-Setup-1.2.2.exe)** · [รีลีสล่าสุด](https://github.com/ThanatZhu/ThanatLive/releases/latest)

## ติดตั้งและเริ่มใช้งาน

1. ดาวน์โหลดและเปิดตัวติดตั้งด้านบน ทำตามหน้าจอ แล้วเปิดไอคอน ThanatLive ไม่ต้องเปิด Start.bat
2. ทำตามตัวช่วยตั้งค่า: เปิด LIVE Studio → เข้าสู่ระบบ TikTok และเปิดแผงแชต → เพิ่ม Link source → เลือกเกมและตรวจภาพ/เสียง
3. Link source คือ `http://127.0.0.1:21213/live.html` ขนาด 576 × 1024 เลือก Fit to screen
4. เมื่อพร้อม กด **Go LIVE ใน TikTok LIVE Studio** แล้วใช้ ThanatLive ควบคุมเกม

มีเกมฟรี 1 เกมให้ทดลอง เกมเต็มใช้บัญชีที่ผู้ขายเปิดสิทธิ์ให้ ตัวช่วยตั้งค่าย้อนกลับ ทำภายหลัง และเปิดดูซ้ำได้จากเมนู **เริ่มไลฟ์**

## ผู้ใช้ Desktop รุ่น 1.2.0–1.2.1

ต้องติดตั้ง 1.2.2 ทับด้วยตัวเอง **ครั้งเดียว** เนื่องจากเปลี่ยนกุญแจและช่องทางอัปเดต Windows หลังไม่พบกุญแจเซ็นเดิม รุ่นเก่าไม่สามารถรับกุญแจใหม่นี้ผ่านระบบอัปเดตได้

จบไลฟ์ → ปิด ThanatLive → ดาวน์โหลดตัวติดตั้งด้านบน → ติดตั้งทับตำแหน่งเดิม → เปิดแล้วตรวจว่าขึ้น **1.2.2**

ข้อมูลบัญชีและการตั้งค่า Desktop ยังคงอยู่ใน `%APPDATA%/ThanatLive/data` จาก 1.2.2 เป็นต้นไป ใช้ **อัปเดต → ตรวจอัปเดต → ติดตั้ง** หลังจบไลฟ์ โปรแกรมตรวจ SHA-256 และลายเซ็นก่อนเปิดตัวติดตั้ง

## ผู้ใช้ ZIP รุ่น 1.1.0

ติดตั้ง Desktop ใหม่ แล้วเลือก **เคยใช้ ThanatLive รุ่นเดิม? → นำเข้าข้อมูลเดิม** ในหน้าต้อนรับ เลือกโฟลเดอร์ ZIP เดิมเพื่อย้ายข้อมูล ตรวจว่าข้อมูลครบก่อนเก็บโฟลเดอร์เก่า

[ชุด ZIP 1.1.0 เดิม](https://github.com/ThanatZhu/ThanatLive/releases/tag/v1.1.0) ยังอยู่ ช่องทาง latest.json คงข้อมูลเดิม ส่วน Windows 1.2.2 ขึ้นไปใช้ latest-windows.json ไม่ต้องดาวน์โหลด JSON เอง

## ข้อควรรู้

ตัวติดตั้งยังไม่มีใบรับรองผู้เผยแพร่ Windows (Authenticode) จึงอาจมีข้อความเตือนจาก Windows ลายเซ็นอัปเดต Ed25519 เป็นการตรวจสอบอีกส่วนหนึ่ง ควรดาวน์โหลดจากรีลีสใน repository นี้เท่านั้น

การเข้าสู่ระบบ TikTok สิทธิ์ Go LIVE และการเชื่อม LIVE Studio ต้องตรวจบนเครื่องผู้ใช้งานจริง พื้นที่นี้ใช้เผยแพร่ตัวติดตั้งและข้อมูลอัปเดต สิทธิ์เกมเต็มขึ้นอยู่กับบัญชีที่ผู้ขายเปิดให้
